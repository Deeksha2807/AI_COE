# AI/ML Workshop Projects

This repository contains three projects completed as part of the AI/ML Workshop.

## Project 1: ANN Binary Classification Using Make Moons

**Objective:** To build an Artificial Neural Network (ANN) that classifies data into two classes using the Make Moons dataset from Scikit-learn.

**Technologies:** Python, Scikit-learn, TensorFlow/Keras, Matplotlib.

**Description:**
- Generate a two-class dataset using Make Moons.
- Build and train an ANN model.
- Evaluate the model's classification performance.
- Visualize the dataset and results.

**File:** `ANN_Moons_Classification.ipynb`

## Project 2: CNN-Based Dog vs. Cat Image Classification

**Objective:** To develop a Convolutional Neural Network (CNN) for classifying dog and cat images using three convolutional layers.

**Technologies:** Python, TensorFlow/Keras, NumPy, Matplotlib.

**Description:**
- Prepare and preprocess image data.
- Build a CNN with three convolutional layers.
- Train and evaluate the model.
- Examine classification accuracy.

**File:** `CNN_Based_Dog_vs_Cat_Image_Classification.ipynb`

## Project 3: Transformer-Based Next-Token Prediction

**Objective:** To demonstrate next-token prediction using a Transformer-style model with self-attention.

**Technologies:** Python, TensorFlow/Keras, NumPy.

**Description:**
- Prepare sample token sequences.
- Use an embedding layer to represent tokens.
- Apply multi-head self-attention.
- Train the model to predict the next token.

**File:** `Transformer_Next_Token_Prediction.ipynb`

## How to Run

1. Open a notebook in this repository.
2. Select **Open in Colab**, or download the notebook and upload it to Google Colab.
3. Run the cells in order.

## Conclusion

These projects demonstrate basic concepts in artificial intelligence and machine learning, including neural networks, image classification, and self-attention.
